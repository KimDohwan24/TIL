Harness, CLAUDE.md, AGENTS.md의 역할과 차이

배포 자동화 플랫폼과 AI 작업 가이드 문서를 함께 정리하기

2026년 04월 27일 7분 읽기

#Harness#AI#Documentation

들어가며

Harness, CLAUDE.md, AGENTS.md는 모두 작업 효율을 높이는 데 쓰이지만, 다루는 대상이 다르다.

  • Harness는 빌드·테스트·배포·검증·롤백 같은 소프트웨어 전달 과정을 관리하는 플랫폼이다.
  • CLAUDE.md는 Claude Code가 프로젝트 작업 시 참고하는 프로젝트 지침 문서다.
  • AGENTS.md는 여러 AI 코딩 도구에서 사용하는 에이전트 작업 지침의 관례다. 역할 분담도 담을 수 있지만, 파일 자체가 역할 분담만을 뜻하지는 않는다.

즉, Harness는 서비스를 운영 환경까지 안전하게 전달하는 문제를 다루고, 나머지 두 문서는 AI가 프로젝트 안에서 일관되게 작업하도록 돕는다.

Harness란

Harness는 CI/CD와 소프트웨어 전달 과정을 자동화·관리하는 플랫폼이다. 개발자가 main 브랜치에 변경 사항을 병합하면 빌드, 테스트, 스테이징 배포, 검증, 운영 배포와 롤백 같은 단계를 파이프라인으로 실행할 수 있다.

핵심은 사람이 순서를 기억하며 수동 배포하던 과정을 표준화하는 것이다. 승인 단계, 배포 이력, 검증 기준을 함께 관리할 수 있어 휴먼 에러를 줄이고 장애 대응을 빠르게 만든다. 다만 도구를 도입하는 것만으로 안전한 배포가 완성되지는 않으며, 테스트·승인·롤백 기준을 팀에 맞게 설계해야 한다.

Harness 자체에 관한 자세한 설명은 이전 글인 Harness란에서 정리했다.

CLAUDE.md란

CLAUDE.md는 Claude Code가 프로젝트를 이해하고 작업할 때 읽는 지침 파일이다. 보통 프로젝트 개요, 실행·테스트 명령어, 코드 스타일, 수정하면 안 되는 영역, 리뷰 기준 등을 담는다.

사람이 새 프로젝트에 합류할 때 온보딩 문서를 읽는 것처럼, AI도 명시적인 문맥이 있어야 추측 대신 프로젝트의 실제 규칙을 따를 수 있다. 다만 CLAUDE.md라는 파일명과 자동 인식 방식은 Claude Code의 규칙이므로, 다른 도구가 같은 파일을 자동으로 읽는다고 가정하면 안 된다.

보통 들어가는 내용

  • 프로젝트 구조와 주요 도메인
  • 실행·테스트·검증 명령어
  • 코드 스타일과 네이밍 규칙
  • 변경하면 안 되는 파일 또는 디렉터리
  • 작업 후 확인할 항목과 커밋·리뷰 원칙

문서는 짧고 검증 가능하게 유지하는 편이 좋다. 오래된 명령어와 규칙은 AI를 더 정확하게 만드는 것이 아니라 잘못된 방향으로 이끈다.

AGENTS.md란

AGENTS.md는 AI 에이전트가 따라야 할 프로젝트 지침을 담는 파일명 관례다. 지원하는 도구와 탐색 범위는 도구마다 다르지만, 보통 저장소 루트 또는 하위 디렉터리에 두어 해당 범위의 규칙을 설명한다.

CLAUDE.md와 비슷하게 실행 방법, 스타일, 테스트 기준을 담을 수 있다. 여기에 writer, reviewer, publisher처럼 역할과 작업 순서를 정의할 수도 있지만, AGENTS.md의 본질이 역할 분담인 것은 아니다. 역할 분담은 여러 에이전트를 실제로 운영할 때 선택적으로 추가하는 워크플로우다.

역할을 정의할 때의 예시

  • writer: 초안 또는 구현안 작성
  • reviewer: 기술 정확성·테스트·문장 품질 점검
  • publisher: 발행 전 링크, 형식, 메타데이터 확인

작은 프로젝트에서는 공통 지침 하나만으로 충분할 수 있다. 역할을 너무 잘게 나누면 검토 비용과 문서 관리 비용이 커진다.

세 가지의 차이

항목 주된 대상 역할 주의할 점
Harness 빌드·테스트·배포·운영 소프트웨어 전달 파이프라인을 자동화하고 가시화 파이프라인 기준과 운영 정책을 함께 설계해야 한다
CLAUDE.md Claude Code 작업 Claude Code에 프로젝트 문맥과 규칙 전달 다른 도구의 자동 인식 여부는 별도로 확인해야 한다
AGENTS.md AI 에이전트 작업 도구가 지원하는 범위에서 프로젝트·디렉터리별 지침 전달, 필요하면 역할 흐름 정의 지원 도구와 지침 우선순위를 확인해야 한다

마무리

셋은 이름이 비슷해 보여도 해결하는 문제가 다르다.

  • Harness는 코드가 운영 환경까지 안전하게 전달되게 한다.
  • CLAUDE.md는 Claude Code가 프로젝트 규칙을 이해하게 한다.
  • AGENTS.md는 지원하는 AI 에이전트가 범위별 지침을 따르게 한다.

새 도구나 문서를 볼 때는 파일명만 보지 말고, 누가 읽는지, 어느 범위에 적용되는지, 어떤 문제를 줄이려는지를 함께 확인하는 것이 중요하다.
